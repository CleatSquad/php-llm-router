# Security Policy

## Supported Versions

Security fixes are applied to the latest stable release.

| Version | Supported |
| ------- | --------- |
| 4.x     | Yes       |
| 3.x     | Security fixes only |
| < 3.0   | No        |

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for a security vulnerability.

Report it privately through [GitHub Security Advisories](https://github.com/CleatSquad/php-llm-router/security/advisories/new), or by email to <mimou78@gmail.com>.

Include a description of the issue, affected version, and reproduction steps. You can expect an acknowledgement within 48 hours.
